# g4c · Ingranaggi & Arcani (prototipo di playtest)

Prototipo HTML mobile di un gioco di carte 4×4 a catture. Apri `index.html` (o la pagina GitHub Pages del repository) da telefono o browser: nessuna installazione.

- 25 carte attive, collezione da sbloccare con campagna (tutorial) e partite contro la CPU
- Draft in 5 round, regole opzionali Same, Plus, Combo, Elementi
- Prototipo per playtest, non il prodotto finale
